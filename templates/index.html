Read the fine print.

No surprises. A few things to know before you start breaking things.

What is httptoy?

httptoy is an open-source HTTP testing API. It provides request inspection, response fixtures, fault simulation, streaming, authentication examples, and short-lived workflow sandboxes for testing HTTP clients.

Is httptoy an alternative to httpbin?

Yes. httptoy covers common httpbin-style use cases such as request echoes, status codes, redirects, cookies, and compression, plus bounded workflow sessions, idempotency fixtures, and Prometheus metrics. Check the API reference when adapting existing tests.

Do I need an API key?

Stateless test endpoints do not require an API key. Workflow sandboxes require the unique bearer token returned when you create a session. Authentication endpoints are protocol fixtures, not production identity services.

Can I run it on my own machine?

Yes. Clone the repository and run the Go server, or build the included Docker image. The frontend and its assets are embedded in the binary; no frontend server is needed in production.

What are the limits?

Echo bodies and compressed/expanded upload data are capped at 1 MiB. Delays are capped at 10 seconds. Sessions expire within 10 minutes, have bounded capture storage, and share finite process-wide admission limits. The capabilities endpoint and README describe each limit.

Is it safe to send production data?

No. Use synthetic test data. Common sensitive capture headers are redacted, but URLs, request bodies, and other values can still contain secrets. For remote deployment, use TLS, access controls, and monitoring-network restrictions.
